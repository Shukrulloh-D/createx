# Задание

Сверстать многостраничный сайт онлайн-школы (Createx Online School — уточнить по макету): главная, каталог курсов, страница курса, список событий (два варианта отображения), страница события, «О нас», блог, страница статьи, контакты, модальные окна входа и регистрации. Сайт многостраничный (десктоп + адаптив под планшет и мобильные устройства).

## Общие элементы
- **шапка** — логотип слева, по центру — горизонтальное меню («О нас», «Курсы», «События», «Блог», «Контакты» — точные подписи уточнить по макету), справа — кнопка-акцент «Получить консультацию» (оранжево-красная) и ссылка «Войти / Регистрация»;
-  блок подписки на рассылку перед футером — розовый/персиковый фон, заголовок («Subscribe to our newsletter» — уточнить по макету), поле email, кнопка, декоративная разноцветная иллюстрация по нижнему краю;
-  футер — тёмный фон, логотип и краткое описание, ссылки по разделам, контакты (телефон, email), иконки соцсетей, копирайт и ссылка «Наверх» внизу;
-  сквозная светлая цветовая схема с белыми и светло-серыми секциями;
-  акцентный цвет — оранжево-красный (кнопки, метки, ссылки);
-  нежно-розовые/персиковые фоны в hero и промо-блоках;
-  плоские цветные иллюстрации; карточки курсов с единообразной структурой: фото преподавателя на цветном (жёлтом) фоне — цветная метка категории — название курса — цена — имя преподавателя;
-  карточки событий с единообразной структурой: дата (число + месяц) — время — название — тип/формат — кнопка «Подробнее»;
-  карточки статей блога с единообразной структурой: обложка — тип материала (статья/видео/подкаст) — категория и дата — заголовок — краткий анонс — ссылка «Читать».

## Страницы

- **Главная**
  — (Home) — hero-баннер на розовом фоне с промо-слоганом («Enjoy studying with Createx Online Courses»
  — уточнить по макету), кнопками «О нас» / «Каталог курсов» и иллюстрацией; кнопка воспроизведения промо-видео; блок со счётчиками достижений (число студентов, курсов, преподавателей и т.п.); блок «Кто мы»
  — фото + текст с преимуществами и кнопкой; сетка популярных курсов с фильтром-табами по категориям и кнопкой «Смотреть все курсы»; блок «Почему стоит выбрать нас» / преимущества обучения с табами и иллюстрацией; блок ближайших событий (список карточек событий) с кнопкой «Смотреть все»; блок сертификата («Ваши знания будут подтверждены») с изображением сертификата и логотипами партнёров; блок команды
   — сетка карточек преподавателей с фото и ссылками на соцсети; слайдер отзывов студентов; блок последних статей блога (3 карточки); блок подписки и **футер**.

## Courses (каталог курсов) — заголовок страницы, табы-фильтры по категориям с количеством курсов, поиск по курсам; сетка карточек курсов; кнопка «Загрузить ещё»; слайдер отзывов студентов; блок сертификата; блок подписки и футер.

 -  Course (страница курса) — заголовок с названием курса; блок «О курсе» — описание, список ключевых пунктов, боковая плашка с датой старта, длительностью, ценой и кнопкой «Записаться»; блок преподавателя — фото, имя, специализация, рейтинг, статистика, описание; блок «Для кого этот курс» — карточки целевых групп; блок «Программа курса» — аккордеон с уроками по неделям; промо-плашка со скидкой / таймером обратного отсчёта (уточнить по макету); блок «Чему вы научитесь» — список навыков с иллюстрацией; слайдер отзывов; форма регистрации на курс (имя, email, телефон) с иллюстрацией; блок «Вам может понравиться» — слайдер карточек других курсов; футер.

  Events List (события — вид списком) — заголовок страницы; панель фильтров: выбор категории, сортировка, количество на странице, поиск, переключатель вида (список/сетка); вертикальный список карточек событий; пагинация; блок подписки и футер.

  Events Grid (события — вид сеткой) — та же панель фильтров, что и на Events List; карточки событий в сетке в несколько колонок; пагинация; блок подписки и футер.

  Event (страница события) — заголовок с названием события, таймер обратного отсчёта до начала; блок «Что вы узнаете» — список пунктов и боковая плашка с датой, временем, местом/форматом, ценой и кнопкой регистрации; блок спикера — фото, имя, должность, описание, соцсети; блок «Для кого это событие» с иллюстрацией; промо-плашка на розовом фоне; форма регистрации на событие с иллюстрацией; блок «Вам может быть интересно» — карточки других событий и кнопка «Смотреть все»; футер.

  About Us (о нас) — hero-блок с заголовком («Createx Online School» — уточнить по макету), описанием, кнопкой видео и иллюстрацией; блок фото-коллажа и ценностей школы; счётчики достижений; блок «Что мы делаем» — сетка карточек направлений; блок «Как мы работаем» — шаги процесса; блок «Наша команда» — сетка карточек преподавателей; слайдер отзывов; блок логотипов компаний, где работают выпускники; блок последних статей блога; блок подписки и футер.

  Blog (блог) — заголовок страницы («Createx School Journal» — уточнить по макету); панель фильтров: табы по типу материала (все / статьи / видео / подкасты), выбор категории, поиск; сетка карточек статей (включая карточку-баннер во всю ширину, если предусмотрена макетом); пагинация; блок подписки и футер.

  Single Post (страница статьи) — метаданные (тип материала, категория, дата, время чтения / длительность), заголовок; крупное обложечное изображение (или видеоплеер/аудиоплеер для соответствующего типа); текст статьи с подзаголовками, цитатой, списками, изображениями; боковая колонка — поиск, категории, карточка автора, популярные материалы, теги, промо-баннер (уточнить по макету); блок тегов и кнопок «Поделиться»; промо-блок (подписка / курс) с иллюстрацией; блок «Вам может понравиться» — слайдер карточек статей; футер.

  Contacts (контакты) — блок «Свяжитесь с нами» — контактная информация (адрес, телефон, email), иконки соцсетей; карта с отметкой офиса; форма обратной связи («Напишите нам» — имя, email, телефон, сообщение, чекбокс согласия, кнопка отправки) с иллюстрацией; футер.

  Sign In / Sign Up — модальные окна поверх страницы с тёмным полупрозрачным оверлеем, кнопка закрытия; Sign In — заголовок, email, пароль с кнопкой показа, чекбокс «Запомнить меня», ссылка «Забыли пароль?», кнопка входа, вход через соцсети, ссылка на регистрацию; Sign Up — заголовок, имя, email, пароль, подтверждение пароля, чекбокс «Запомнить меня», кнопка регистрации, вход через соцсети, ссылка на вход; открываются по клику на «Войти / Регистрация» в шапке, закрываются по крестику, клику на оверлей и клавише Esc.

  Адаптивность десктоп — многоколоночные сетки карточек (курсы, команда, статьи, события-сетка), боковая колонка на странице статьи и боковые плашки на страницах курса и события; планшет — сетки сужаются до 2–3 колонок, меню сворачивается в бургер, боковые колонки и плашки уходят под основной контент, иллюстрации уменьшаются или переносятся под текст; мобильная версия — всё в один стек, карточки в вертикальном списке, табы-фильтры прокручиваются горизонтально, слайдеры листаются свайпом, формы, карта и модальные окна входа/регистрации — на всю ширину экрана.

  Интерактив бургер-меню на планшете и мобильных; табы-фильтры курсов и статей; аккордеон программы курса; слайдеры отзывов и блоков «Вам может понравиться»; переключатель вида событий (список/сетка); таймер обратного отсчёта на страницах курса/события; модальные окна входа и регистрации; кнопка «Наверх» в футере.

## Дизайн

  Светлый фон как основной; оранжево-красный акцентный цвет для кнопок, меток и активных состояний; нежно-розовые/персиковые фоны в hero, промо-плашках и блоке подписки; тёмный футер; плоские цветные иллюстрации как главный визуальный ряд; фото преподавателей на жёлтом фоне в карточках курсов; тёмный полупрозрачный оверлей для модальных окон входа и регистрации; карточки курсов, событий и статей с единообразной структурой.
